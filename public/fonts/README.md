# Self-hosted fonts

These files replace every Google Fonts request made by the site and its legacy static pages.

- Assistant, Nunito, Source Sans 3, and Quicksand: SIL Open Font License 1.1. Assistant's license is at `src/assets/fonts/Assistant/OFL.txt`.
- Open Sans and Droid Sans: Apache License 2.0.

Browser fonts are WOFF2 and were downloaded from Google Fonts' official static font endpoints.
`assistant-regular.ttf` and `assistant-semibold.ttf` are duplicate build-time inputs for Satori,
which does not support WOFF2.
